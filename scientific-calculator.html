Scientific Calculator

Full-featured scientific calculator with trig, log, memory, and keyboard support.

0

About this scientific calculator

This free online scientific calculator provides all the functions of a standard scientific calculator in your browser. It supports basic arithmetic (addition, subtraction, multiplication, division), trigonometric functions (sin, cos, tan) with a degree/radian toggle, inverse trig (via expression chaining), square, power (xʸ), square root, logarithm base-10 (log), natural logarithm (ln), absolute value, reciprocal (1/x), percentage, negation, and the mathematical constants π and e. A four-function memory (M+, M−, MR, MC) lets you store and recall intermediate values. Full keyboard input is supported — press numbers, operators, Enter to calculate, and Backspace to delete.

How to use the calculator

Click buttons or type using your keyboard to build an expression. The display shows the current expression as you enter it. Press = or Enter to evaluate. The previous expression is shown in grey above the result as history. Use parentheses for grouping: for example, sin(30) in degree mode gives 0.5. Chain multiple operations in a single expression: sqrt(9) + 2^3 evaluates correctly. Press AC to clear everything or ⌫ to delete the last character. The DEG/RAD button toggles whether trig functions use degrees or radians.

When a scientific calculator is useful

Scientific calculators are essential for STEM education and research: physics problems involving angles and vectors, chemistry calculations with scientific notation and logarithms, engineering formulas, statistics involving natural logarithms, and financial mathematics using exponential growth models. Having a reliable scientific calculator in the browser means you can perform these calculations quickly alongside reference materials, without switching to a physical calculator or a separate application.
